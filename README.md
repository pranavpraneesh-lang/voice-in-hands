# VOICE IN HANDS 

### Turning Hand Signs into Voice

VOICE IN HANDS is an AI-assisted wearable glove prototype designed to recognize selected hand gestures and convert them into text and speech.

The project combines flex sensors, motion sensing, an ESP32 controller, Wi-Fi communication, and a web interface to demonstrate how hand movements can be transformed into accessible communication.

---

##  Project Objective

VOICE IN HANDS explores a simple idea:

**Hand Gesture → Sensor Data → Recognition → Text → Voice**

The goal is to create a technology-assisted communication interface using a wearable glove and embedded sensors.
